# AAC AURA — 와이어프레임 (React)

디자인 요소(색·그라디언트·아이콘)를 뺀 저해상도 와이어프레임입니다.
팀 논의(위치 데이터+rPPG 병행, 워치 유무에 따른 심박수 소스 분기, 러닝 앱 기능+사진찍기+AI 솔루션)를
반영한 최신 화면 흐름입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 화면 흐름

```
홈 (러닝 앱 시작, 스트레칭 제시-선택)
  → 트래킹 (운동 중, 케이던스: 강도·시간·거리·심박수·스트레스·UV지수 자동 수집)
    → 심박확인 (워치 있음 / 워치 없음 분기)
        워치 있음 → 워치 데이터 바로 사용 → 솔루션
        워치 없음 → 스캔 화면(rPPG 사진 찍기) → 솔루션
      → 솔루션 (AI LLM 종합 — 맞춤 추천, 가이드, 스트레칭)
        → 리포트 (주간 추이, 이번 주 심박 데이터 소스 비율)
```

## 구조

```
src/
  App.jsx              화면 전환 상태 관리
  index.css            와이어프레임 스타일 (회색조, 테두리만)
  components/
    Home.jsx           러닝 앱 시작, 스트레칭 제시(선택), 위치·UV 자동 수집
    Tracking.jsx       운동 중 케이던스 데이터 자동 수집
    Vitals.jsx         심박수 데이터 소스 선택 (워치 있음/없음 토글)
    Scan.jsx           rPPG 사진 찍기 (워치 없음 경로)
    Solution.jsx       AI LLM 종합 솔루션 (맞춤 추천·가이드·스트레칭)
    Report.jsx         개인 리포트 (주간 추이, 심박 소스 비율)
    TabBar.jsx          하단 탭 (홈/트래킹/심박확인/솔루션/리포트)
```

모든 시각 요소는 "자리" 표시(placeholder)이며, 실제 디자인은 다음 단계에서 입힙니다.
