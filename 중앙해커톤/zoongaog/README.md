# AAC AURA — 와이어프레임 (React)

디자인 요소(색·그라디언트·아이콘) 없는 저해상도 와이어프레임입니다.
팀원 피드백(홈화면·기록·프로필 추가)과 실제 rPPG 구현 문서(react-native-vision-camera
기반 손가락+플래시 측정)를 반영한 최신 버전입니다.

## 중요 — rPPG 측정 방식 정정

이전 버전은 "얼굴 스캔"으로 설계돼 있었지만, 실제 구현 문서(MeasurementScreen.tsx,
useTorchCamera.ts, bpmProcessor.ts)를 보면 **손가락을 후면 카메라 + 플래시에
밀착시켜 측정**하는 방식입니다. 카메라가 얼굴이 아니라 손가락에 닿는 미세한
밝기 변화(플래시 반사광의 R 채널)를 읽어서 심박수를 계산합니다. 이번 버전은
이 방식대로 전부 수정했습니다.

- 측정 시간: 약 12초 (FPS 20 × 12초 = 240프레임)
- 신호처리: detrend → smooth → findPeaks 로 BPM 계산
- 유효 범위: 40~220bpm 벗어나면 신뢰 불가로 처리
- 에러 문구: "신호가 충분하지 않습니다. 손가락 밀착을 확인하고 다시 시도해주세요." (실제 코드 문구 그대로 사용)
- 측정 버튼 문구: "측정 시작" → 측정 중에는 "측정 중.. 손가락을 떼지 마세요" (실제 코드 문구 그대로 사용)
- 측정 후 백엔드로 전송(POST /api/measurements: bpm, sessionId, measuredAt), 실패 시 재측정 안내

## 실행 방법

```bash
npm install
npm run dev
```

## 화면 흐름

```
홈 (대시보드 · 최근 측정 요약 · 러닝 시작 진입점)
  └ 러닝 시작하기
      → 러닝 준비 (스트레칭 선택)
        → 트래킹 (케이던스: 강도·시간·거리·심박수·스트레스·UV지수)
          → 심박확인 (워치 있음/없음 분기)
              워치 있음 → 솔루션
              워치 없음 → 손가락 측정(rPPG, 12초) → 솔루션
            → 솔루션 (AI 종합 가이드) → 완료 시 기록에 저장

기록 (측정 기록 리스트 - 날짜·방식·BPM·전송 상태)
프로필 (목표·연동 상태·알림 설정)
```

## 구조

```
src/
  App.jsx              탭 전환 + 러닝 다단계 흐름 상태 관리
  index.css            와이어프레임 스타일 (회색조, 테두리만)
  components/
    Home.jsx           대시보드 — 최근 측정 요약, 이번 주 요약, 러닝 시작 진입점
    RunStart.jsx        러닝 준비 — 스트레칭(선택), 위치·UV 확인
    Tracking.jsx        운동 중 케이던스 데이터
    Vitals.jsx          심박수 소스 선택 (워치 / 손가락 측정)
    FingerScan.jsx       손가락 rPPG 측정 — 12초 측정, 실제 코드 문구 반영
    Solution.jsx         AI 종합 솔루션
    History.jsx          측정 기록 리스트 (전송 완료/실패 상태 포함)
    Profile.jsx           목표·연동 상태·알림 설정
    TabBar.jsx            하단 탭 (홈/러닝/기록/프로필)
```
