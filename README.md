# AAC AURA — 와이어프레임 (React)

디자인 요소(색·그라디언트·아이콘) 없는 저해상도 와이어프레임입니다.

## 이번 업데이트 (팀 피드백 반영)

1. **하단 탭에서 "러닝" 제거** — 탭은 홈/기록/프로필 3개로 줄였습니다. 홈에서
   "러닝 시작하기"를 누르면 탭 이동이 아니라 **전체화면 오버레이**(팝업처럼
   화면 전체를 덮는 방식)로 러닝 흐름이 열립니다. 상단 "닫기 ✕"로 언제든
   홈으로 돌아갈 수 있고, 솔루션까지 완료하면 자동으로 닫히며 기록 탭으로
   이동합니다.
2. **rPPG/워치 심박수 결과를 큰 숫자로 강조** — 기존엔 다른 항목들과 같은
   줄에 작게 표시돼 눈에 안 들어온다는 피드백이 있어, 결과 화면(FingerScan,
   Vitals, Solution)에 `.result-hero` 카드로 심박수를 44px 크기로 강조했습니다.
3. **로그인 / 회원가입 화면 추가** — 앱 진입 시 가장 먼저 뜨는 화면입니다
   (`Login.jsx`). 로그인/회원가입 탭 전환, 이메일·비밀번호 입력 필드를
   포함합니다. 로그인 버튼을 누르면 메인 앱(홈/기록/프로필)으로 진입합니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 화면 흐름

```
로그인/회원가입
  → 홈 (대시보드 · 최근 측정 요약 · 러닝 시작 진입점)
      └ "러닝 시작하기" → 전체화면 오버레이로 전환
          러닝 준비(스트레칭 선택) → 트래킹 → 심박확인(워치/손가락 분기)
            워치 있음 → 솔루션
            워치 없음 → 손가락 측정(rPPG, 12초, 결과 강조) → 솔루션
          → 완료 시 오버레이 닫히고 기록 탭으로 이동
  기록 (측정 기록 리스트)
  프로필 (목표·연동 상태·알림 설정)
```

## rPPG 측정 방식 (실제 구현 문서 반영)

손가락을 후면 카메라 + 플래시에 밀착시켜 측정합니다(얼굴 스캔 아님).

- 측정 시간: 약 12초 (FPS 20 × 12초 = 240프레임)
- 신호처리: detrend → smooth → findPeaks 로 BPM 계산
- 유효 범위: 40~220bpm 벗어나면 신뢰 불가로 처리
- 에러 문구: "신호가 충분하지 않습니다. 손가락 밀착을 확인하고 다시 시도해주세요." (실제 코드 문구)
- 버튼 문구: "측정 시작" → 측정 중 "측정 중.. 손가락을 떼지 마세요" (실제 코드 문구)
- 측정 후 백엔드 전송(POST /api/measurements: bpm, sessionId, measuredAt), 실패 시 재측정 안내

## 구조

```
src/
  App.jsx              로그인 게이트 + 탭 전환 + 러닝 오버레이 상태 관리
  index.css            와이어프레임 스타일 (회색조, 테두리만)
  components/
    Login.jsx           로그인/회원가입
    Home.jsx             대시보드 — 최근 측정 요약, 러닝 시작 진입점
    RunStart.jsx          러닝 준비 (오버레이 1단계)
    Tracking.jsx           운동 중 케이던스 데이터 (오버레이 2단계)
    Vitals.jsx              심박수 소스 선택 — 결과 강조 카드 포함 (오버레이 3단계)
    FingerScan.jsx           손가락 rPPG 측정 — 결과 강조 카드 포함 (오버레이 3단계 대체)
    Solution.jsx              AI 종합 솔루션 — 측정 결과 강조 카드 포함 (오버레이 4단계)
    History.jsx               측정 기록 리스트
    Profile.jsx                목표·연동 상태·알림 설정
    TabBar.jsx                 하단 탭 (홈/기록/프로필)
```
