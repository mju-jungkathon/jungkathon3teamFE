# 🏃 다음 러닝 시점 추천 기능 — 프론트엔드 개발 문서

> 작성일: 2026-08-20
> 대상: AfterGrow 프론트엔드
> 관련 도메인: `recovery` (화면 7 — 회복 가이드)
> 목표: 회복 가이드 화면에 다음 러닝 추천 시점 카드 추가

---

## 0. 기능 개요

**추천 로직 (백엔드 규칙 기반, AI 미사용)**

```
추천 시점 = 회복 완료 예상 시각 이후 & UV 지수가 낮은 시간대
```

프론트는 백엔드가 계산한 결과(`recommendedTime`, `reason`, `expectedUvIndex`)를 받아 회복 가이드 화면(화면 7) 하단에 표시하기만 하면 됨.

> 백엔드 엔드포인트: `GET /recovery-guides/{recoveryGuideId}/next-run-suggestion`
> 응답 스펙은 백엔드에서 먼저 확정 후 공유받아야 함 — 확정 전까지는 아래 목업 타입으로 UI 우선 개발 가능

## 2. 타입 정의

```ts
// shared/api/types.ts
export interface NextRunSuggestion {
  recommendedTime: string | null;
  reason: string;
  expectedUvIndex: number | null;
}
```

---

## 3. API 함수

```ts
// domains/recovery/api/recoveryApi.ts
export async function fetchNextRunSuggestion(
  recoveryGuideId: string
): Promise<ApiResponse<NextRunSuggestion>> {
  const res = await apiClient.get(
    `/recovery-guides/${recoveryGuideId}/next-run-suggestion`
  );
  return res.data;
}
```

---

## 4. React Query 훅

```ts
// domains/recovery/hooks/useNextRunSuggestion.ts
export function useNextRunSuggestion(recoveryGuideId: string) {
  return useQuery({
    queryKey: ['recoveryGuide', recoveryGuideId, 'nextRunSuggestion'],
    queryFn: () => fetchNextRunSuggestion(recoveryGuideId),
    enabled: !!recoveryGuideId,
  });
}
```

---

## 5. UI 배치

- 위치: 회복 가이드 화면(화면 7) 최하단, 기존 회복 액션 리스트 아래
- 디자인: Exposure Ring 톤 유지 (다크 패널 + UV 앰버 `#f5a623` 배지 재사용)
- 콘텐츠:
  - 추천 시각: "다음 러닝은 8/21(금) 오전 7시가 좋아요"
  - 근거: `reason` 텍스트 짧게 병기
  - UV 배지: `expectedUvIndex` 표시 (있을 경우)

---

## 6. 상태 처리

| 상태 | UI 처리 |
|---|---|
| 로딩 중 | 스켈레톤 카드 |
| `recommendedTime: null` (fallback) | `reason` 메시지만 조용히 표시, 에러 스타일 아님 |
| API 자체 실패 (네트워크 에러) | 카드 숨김 처리 — 메인 회복 가이드 표시를 방해하지 않음 |
